# Authentication

Access the Content Management System (CMS) at the following link:

`https://<your-site>/admin`

If you need to login, the system will show a "Login to GitHub" button.

From here, you will either be automatically logged in (skip to "Home Page" below) or will need to login and/or authorize access.

If you need to login, you'll see the following screen.  Use the same credentials (username/password) that you use to sign in to GitHub.

If you need to authorize, you'll see the following screen.  Click "Authorize", and then you'll be forwarded to the Boardify Home Page.
