# Using Microsoft Word

You can write your content in Microsoft Word, using all of the normal features like bold, headings, bullet points, etc.  Then you can copy over that work into Boardify using the following instructions.

It's a fairly straightforward process, but does require a few steps and some attention to detail.  You will also need to get the [Writage](https://www.writage.com) plugin for Word and have it installed before you begin (ask tech support for help to do this.)

## Export from Boardify into Word

Here are the steps to export a Boardify draft into Microsoft Word.

1. Go to the policy on Boardify, click on it, and scroll down to the 'Content' section.  (Don't worry about the upper portion -- you can just enter that directly.)

2. Toggle button from "Rich Text" to "Markdown".  This will change the main text from WYSIWYG to Markdown format. **Note:** It is easy to forget this step, and it will *seem* like it's working anyway.  But if you forget to do this it will not export properly.

3. Select the entire text and copy it (the normal way you copy/paste.)

4. Next, open up your Word doc for the policy.  If it is an existing doc then be sure you select all the text as you would when planning to replace with what you have copied.  Alternatively, start with a new, empty Word doc.

5. With the text selected OR the cursor at the top of the page, click the "Paste Markdown" button from the Writage Toolbar in the Word doc.  The content will be put into Word, and all of the formatting will be preserved.

6. Save it!

From here, do what you need to do in Word, reformatting, rearranging, etc.  Save and share it as normal.  Treat it like any other Word document -- just be sure to follow the conventions found in the Policy Style Guide.

Then, when you are ready to bring it back into Boardify, follow the Import directions below.


## Import from Word into Boardify

When you want to export a Word document into Boardify, follow these steps:

1. Open your Word doc.

2. Select the entire text and choose "Copy Markdown" from the Writage Toolbar in the Word document.

3. Go to the policy on Boardify that you want to update with your Word doc, click on it, and scroll down to the 'Content' section.

4. Toggle button from "Rich Text" to "Markdown".  This will change the main text from WYSIWYG to Markdown format. **Note:** It is easy to forget this step, and it will *seem* like it's working anyway.  But if you forget to do this it will not import properly.

5. Put your cursor in the 'Content' section, and select all the text like you normally would when replacing text through a copy/paste.

6. Paste the text (in the normal way you copy/paste.)

7. Click "Save" to save your imported changes.

Things are now updated in Boardify.  If needed, change the status but otherwise you are good to go.

---

To learn more about Writage, visit the [Writage Website](https://www.writage.com) to understand how it works.  But the main point to remember is that everything needs to go in and out of Boardify and Word in the Markdown format.  If you try to copy/paste in either without taking this step (including switching the toggle) then it will not work properly even if it seems to do so.  There will be hidden characters that will cause problems; so again, please follow the directions.
